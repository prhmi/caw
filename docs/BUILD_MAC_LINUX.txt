CAW - BUILD INSTRUCTIONS FOR macOS AND LINUX
============================================

Source: caw_clean.zip (the clean version with all changes).
The first build needs internet: it downloads ImGui, PortAudio, GLFW and the
VST3 SDK once into ~/.caw_deps. Later builds work offline.


------------------------------------------------------------
PART 1 - macOS
------------------------------------------------------------

1. Install Apple's compiler (once)
   Open Terminal and run:

       xcode-select --install

   A window opens. Click "Install" and wait until it finishes.

2. Install Homebrew (once, skip if you already have it)
   Go to https://brew.sh and copy the install command shown there into Terminal.
   At the end it prints 2 lines starting with "echo" / "eval". Run them too.

3. Install the build tools (once)

       brew install cmake ninja git

4. Copy CAW to the Mac
   Put caw_clean.zip in your Downloads folder, then:

       mkdir -p ~/caw
       cd ~/caw
       unzip ~/Downloads/caw_clean.zip
       chmod +x build.sh

5. Build

       ./build.sh nostart

   For Apple Silicon AND Intel Macs in one app:

       CAW_UNIVERSAL=1 ./build.sh nostart

   If the VST part blocks the build, build without it first:

       ./build.sh nostart -DCAW_VST3=OFF

6. If it fails
   Send these files:
       ~/caw/caw_build.log       (build errors)
       ~/caw/caw_configure.log   (if it stopped before building)
   To open the folder in Finder:  open ~/caw

7. If it works
   The app is:  ~/caw/build/caw.app
   First start: right-click caw.app > Open > Open
   (macOS blocks apps not signed by a registered Apple developer.)

8. After the first start
   - Install Csound for macOS (csound.com), then set its path in
     Settings > Programs. Same for SuperCollider / Pure Data if you use them.
   - System Settings > Privacy & Security > Microphone: allow CAW if you
     use audio input.
   - VST3 plugins load from /Library/Audio/Plug-Ins/VST3 and
     ~/Library/Audio/Plug-Ins/VST3. They play, but plugin WINDOWS do not open
     yet on macOS (needs Mac window code - next step after the build works).


------------------------------------------------------------
PART 2 - LINUX (on your Windows PC, with WSL)
------------------------------------------------------------

1. Install Ubuntu (once)
   Open PowerShell as administrator and run:

       wsl --install -d Ubuntu

   Restart Windows if asked. Open "Ubuntu" from the Start menu and choose a
   user name and password.

2. Install the build tools (once, in Ubuntu)

       sudo apt update
       sudo apt install -y build-essential cmake ninja-build git unzip \
         libasound2-dev libjack-jackd2-dev libgl1-mesa-dev \
         libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev \
         libxkbcommon-dev libwayland-dev wayland-protocols fonts-dejavu

3. Copy CAW and build
   (change the path to where caw_clean.zip is on your PC)

       mkdir -p ~/caw
       cd ~/caw
       unzip /mnt/c/Users/Parham/Downloads/caw_clean.zip
       chmod +x build.sh
       ./build.sh nostart

   Build inside ~/caw (not on /mnt/c) - it is much faster.

4. If it fails
   Send ~/caw/caw_build.log
   In Windows Explorer it is at:
       \\wsl$\Ubuntu\home\<your-user>\caw\caw_build.log

5. If it works
   Start it:   ./build/caw
   (On Windows 11 the window opens through WSL. Sound in WSL is limited -
   the real test is on a Linux PC.)

6. On a real Linux PC (Ubuntu / Debian)
   Same steps 2-3. Other distributions need the same packages under their
   names, for example Fedora:
       sudo dnf install gcc-c++ cmake ninja-build git alsa-lib-devel \
         jack-audio-connection-kit-devel mesa-libGL-devel libX11-devel \
         libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel \
         libxkbcommon-devel wayland-devel dejavu-sans-fonts


------------------------------------------------------------
WHAT TO EXPECT
------------------------------------------------------------
- CAW was compiled only with Visual Studio until now, so the first
  macOS / Linux build will most likely show a few errors. Send the log,
  I fix them, you build again - repeat until it builds.
- Known limits on macOS / Linux (for now):
    * VST plugin windows do not open (plugins still play).
    * A crashing plugin crashes CAW (on Windows CAW catches it).
    * Csound, Pure Data, SuperCollider and FFmpeg must be installed
      separately and set in Settings > Programs.
